# Learn Economics

经济学学习笔记：以宏观周期为主线，理解经济增长、货币政策与流动性如何影响资产价格，并落到投资决策框架。

## 目录

### 一、长周期与投资框架

1. [康波周期理论](./康波理论.md)
   - 50–60 年技术长波的驱动力、春夏秋冬四阶段与历史波次；结合美林投资时钟做中短期资产轮动，并给出当前周期位置的资产配置与职业选择启示。

### 二、美联储、利率与流动性

2. [美联储加息降息与美债收益率](./美联储加息降息与美债收益率.md)
   - FOMC 加息／降息的决策逻辑、美债收益率曲线与全球资产定价之锚；政策通过美元和资本流动的外溢影响，以及股票、债券、黄金等资产的应对框架。

3. [美联储资产负债表详解](./美联储资产负载表.md)
   - 资产负债表的构成与 2008 年以来的演变、QE 扩表与 QT 缩表的机制差异；净流动性、银行准备金等指标对各类资产的影响和每周观察清单。

## 阅读顺序建议

**康波周期理论**（定长期基调）→ **美联储加息降息与美债收益率**（资金的价格）→ **美联储资产负债表详解**（资金的数量）。

三者结合，形成「长波定方向、利率定估值、流动性定波动」的宏观视角。

## 阅读顺序建议

**康波周期理论**（定长期基调）→ **CPI与PPI** ／ **非农 NFP**（读懂数据）→ **美联储如何出牌**（数据如何变成政策）→ **加息降息与美债收益率**（资金的价格）／ **资产负债表**（资金的数量）→ **宏观大考下的交易纪律**（落到执行）→ **大宗商品**（把宏观变量落到实物资产）→ **黄金价格驱动因素与买入时机**（聚焦单一资产）。

串起来就是「长波定方向、数据定预期、利率定估值、流动性定波动、纪律定结果」。

**股票投资技术分析**及其四篇专题（**移动平均线**／**MACD**／**RSI**／**布林带**）是另一条独立主线：不依赖宏观数据，从价量与指标出发解决「何时买卖」，可与上述主线并行阅读，作为择时与风控的补充。第一篇给出指标全貌与有效性证据，后四篇分别深挖趋势骨架（均线）、动量（MACD）、超买超卖（RSI）与波动率（布林带）。建议按「总论 → 均线 → MACD → RSI → 布林带」的顺序读：MACD 完全由均线构造，RSI 的用法也取决于能否先分清趋势市与震荡市；布林带以均线为中轨、用标准差刻画波动环境，放在最后更容易把趋势判断与波动状态结合起来。

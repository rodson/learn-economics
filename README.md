# Learn Economics

经济学学习笔记：以宏观周期为主线，理解经济增长、宏观数据、货币政策与流动性如何影响资产价格，并落到投资决策框架；另有两条独立主线——基本面分析从生意模式与财务质量出发解决「买什么、值不值得买」，技术分析从价量与指标出发解决「何时买卖」。

### 五、技术分析：指标与择时

10. [股票投资技术分析](./股票投资技术分析.md)
    - 均线、MACD、RSI、布林带与成交量五大指标的机制与失效情形；结合学术证据说明为何动量和趋势效应最站得住脚、多数单一指标扣费后难以稳定跑赢买入持有，并给出「先定趋势 → 再找时机 → 量能确认 → 严格风控」的组合框架、A 股制度差异与仓位纪律。

11. [移动平均线完整详解](./移动平均线完整详解.md)
    - 第 10 条中「趋势骨架」的专题深挖：用 N 日均线约滞后 (N−1)/2 天的规律解释「用滞后换平滑」，对比 SMA／EMA／WMA／SMMA／VWMA 的权重与反应速度；说明金叉死叉为何在震荡市系统性失效，以及 200 日线择时的真实价值（降低回撤 ≠ 提高收益）。

12. [MACD技术分析完整详解](./MACD技术分析完整详解.md)
    - 第 10 条中「动量」维度的专题深挖：DIF／DEA／柱状图的构成与 12-26-9 参数，用数值例子说明 DIF 是趋势的「速度」、柱状图才是「加速度」；澄清 MACD 只是均线的再加工、背离不等于反转，并给出「信号越早越不可靠」的排序与指标堆叠的确认陷阱。

13. [RSI技术分析完整详解](./RSI技术分析完整详解.md)
    - 第 10 条中「超买超卖」维度的专题深挖：Wilder 平滑递推与 RSI 公式、14 日参数的含义；从动能速度与仓位拥挤解释超买超卖，讲清背离与失败摆动（Failure Swing）的结构，并指出强趋势中 RSI 钝化、背离后价格仍可继续运行等使用边界。

14. [布林带技术分析完整详解](./布林带技术分析完整详解.md)
    - 第 10 条中「波动率」维度的专题深挖：以 20 日均线为中轨、上下轨取 ±2 倍标准差，并给出带宽（Bandwidth）与 %B 两个衍生指标；从波动率聚集与均值回归、强趋势中的「沿轨运行」解释其底层逻辑，说明收口（Squeeze）为何是变盘预警；强调布林带不预测方向，触轨即反转在单边行情中容易失效，且需防范假突破与参数不适配。

15. [成交量技术分析完整详解](./成交量技术分析完整详解.md)
    - 第 10 条中「量能确认」维度的专题深挖：从量价配合的四种基本组合讲起，梳理成交量均线、OBV、换手率、量比与 VWAP 等工具；说明成交量是唯一不由价格衍生的原始信息，可用来判断趋势健康度、过滤无量假突破、识别天量／地量与量价背离；强调它只衡量「力量」而非方向，需结合换手率与历史量能水平，警惕对倒失真与大小盘流动性差异。

### 六、基本面分析：选股、理解标的与财报阅读

16. [选股与理解标的的底层逻辑](./选股与理解标的的底层逻辑.md)
    - 以「商业模式 → 竞争格局与护城河 → 财务质量 → 管理层与治理 → 估值与安全边际」五层框架拆解如何研究一家公司；给出从定方向、初筛、逐家深入、对比淘汰到形成观察名单与买入后跟踪的选股流程，并强调先懂生意再谈估值、增长要有自由现金流支撑、周期股与成长股用不同的尺子，以及能力圈与概率思维。

17. [如何快速阅读年报](./如何快速阅读年报.md)
    - 第 16 条五层框架在单家公司上的实操落地：用「快速体检 → 精读管理层讨论与分析 → 排查高风险财务项目 → 看内部人行为与股东变化 → 强制输出判断」五步法抓重点，并区分首次研究（1–2 小时）与已跟踪公司的日常年报（30–60 分钟）；强调带着问题读、先看变化与异常、先验证风险再确认亮点，用数据对照管理层的说法，最后留下书面结论，避免只盯净利润或逐页通读的低效做法。

## 阅读顺序建议

**康波周期理论**（定长期基调）→ **CPI与PPI** ／ **非农 NFP**（读懂数据）→ **美联储如何出牌**（数据如何变成政策）→ **加息降息与美债收益率**（资金的价格）／ **资产负债表**（资金的数量）→ **宏观大考下的交易纪律**（落到执行）→ **大宗商品**（把宏观变量落到实物资产）→ **黄金价格驱动因素与买入时机**（聚焦单一资产）。

串起来就是「长波定方向、数据定预期、利率定估值、流动性定波动、纪律定结果」。

**股票投资技术分析**及其五篇专题（**移动平均线**／**MACD**／**RSI**／**布林带**／**成交量**）构成技术分析主线：不依赖宏观数据，从价量与指标出发解决「何时买卖」，可与上述主线并行阅读，作为择时与风控的补充。第一篇给出指标全貌与有效性证据，后五篇分别深挖趋势骨架（均线）、动量（MACD）、超买超卖（RSI）、波动率（布林带）与量能确认（成交量）。建议按「总论 → 均线 → MACD → RSI → 布林带 → 成交量」的顺序读：MACD 完全由均线构造，RSI 的用法也取决于能否先分清趋势市与震荡市；布林带以均线为中轨、用标准差刻画波动环境；成交量是唯一不由价格衍生的原始信息，放在最后正好用来确认和过滤前面各类价格信号，对应总论「量能确认」一环。

**选股与理解标的的底层逻辑**与**如何快速阅读年报**构成基本面主线：这条主线不预测行情，而是回答「买什么、值不值得买」。建议先用「先懂生意 → 护城河 → 财务质量 → 管理层 → 估值与安全边际」五层框架，在能力圈内筛出财务扎实、价格合理的公司；在「逐家深入」环节配合年报五步法，把生意模式、财务质量与管理层可信度落到具体年报上验证，留下书面判断并形成观察名单；再借宏观主线判断环境、借技术分析主线决定买卖点。三条主线串起来就是「基本面选标的、宏观定环境、技术面定时机」，配合仓位管理与风控纪律，才构成从研究到执行的完整闭环。

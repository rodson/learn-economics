# Learn Economics

经济学学习笔记：以宏观周期为主线，理解经济增长、宏观数据、货币政策与流动性如何影响资产价格，并落到投资决策框架。

## 目录

### 一、长周期与投资框架

1. [康波周期理论](./康波理论.md)
   - 50–60 年技术长波的驱动力、春夏秋冬四阶段与历史波次；结合美林投资时钟做中短期资产轮动，并给出当前周期位置的资产配置与职业选择启示。

### 二、宏观数据基础：通胀与就业

2. [CPI与PPI如何左右你的钱包与股市](./CPI与PPI如何左右你的钱包与股市.md)
   - CPI／PPI 的定义与差异、上游成本向下游的传导与「剪刀差」对企业利润的挤压；通胀数据如何改变利率预期与股票估值，以及普通家庭保护购买力的思路。

3. [解码非农数据（NFP）背后的衰退与繁荣](./解码非农数据（NFP）背后的衰退与繁荣.md)
   - 非农报告的构成（新增就业、失业率、平均时薪、修正值）与「萨姆规则」衰退预警；就业数据发布日美元、美债、股市、黄金如何交易「预期差」。

### 三、美联储、利率与流动性

4. [美联储如何根据 CPI、PPI 和非农出牌](<./美联储如何根据 CPI、PPI 和非农出牌.md>)
   - 以「三体问题」比喻双目标决策：通胀与就业的经典权衡、CPI-PPI 传导博弈、三大指标互相打架时的决策流程与预期管理。

5. [美联储加息降息与美债收益率](./美联储加息降息与美债收益率.md)
   - FOMC 加息／降息的决策逻辑、美债收益率曲线与全球资产定价之锚；政策通过美元和资本流动的外溢影响，以及股票、债券、黄金等资产的应对框架。

6. [美联储资产负债表详解](./美联储资产负载表.md)
   - 资产负债表的构成与 2008 年以来的演变、QE 扩表与 QT 缩表的机制差异；净流动性、银行准备金等指标对各类资产的影响和每周观察清单。

### 四、实战：交易纪律与资产配置

7. [宏观大考下的交易纪律与资产配置](./宏观大考下的交易纪律与资产配置.md)
   - 数据发布前／中／后的行动清单、紧缩／软着陆／滞胀／宽松四种宏观状态下的配置偏向，以及「核心-卫星」仓位结构与交易日志复盘纪律。

8. [大宗商品：本质、价格驱动与投资者应对之道](./大宗商品：本质、价格驱动与投资者应对之道.md)
   - 能源、金属、农产品三大类的特性与「不产生现金流」的定价本质；拆解供需与库存、美元与货币政策、地缘、天气、投机资金和边际成本曲线六类驱动，并给出区分「交易」与「配置」、尊重周期与严控仓位的应对原则。

9. [黄金价格驱动因素与买入时机：逻辑与原理深度解析](./黄金价格驱动因素与买入时机：逻辑与原理深度解析.md)
   - 以实际利率（TIPS）为核心锚，拆解美元、通胀预期、避险溢价、央行购金与 ETF 资金流对金价的作用方向；说明为何不追求精准抄底，而是用分批建仓、定投与定期再平衡在回调区间建立长期配置仓位。

10. [股票投资技术分析](./股票投资技术分析.md)
    - 均线、MACD、RSI、布林带与成交量五大核心指标的底层逻辑与适用场景；「先定趋势 → 再找时机 → 量能确认 → 严格风控」的组合框架，以及震荡市／趋势市中指标有效性的差异。

## 阅读顺序建议

**康波周期理论**（定长期基调）→ **CPI与PPI** ／ **非农 NFP**（读懂数据）→ **美联储如何出牌**（数据如何变成政策）→ **加息降息与美债收益率**（资金的价格）／ **资产负债表**（资金的数量）→ **宏观大考下的交易纪律**（落到执行）→ **大宗商品**（把宏观变量落到实物资产）→ **黄金价格驱动因素与买入时机**（聚焦单一资产）。

串起来就是「长波定方向、数据定预期、利率定估值、流动性定波动、纪律定结果」。

**股票投资技术分析**是另一条独立主线：不依赖宏观数据，从价量与指标出发解决「何时买卖」，可与上述主线并行阅读，作为择时与风控的补充。
